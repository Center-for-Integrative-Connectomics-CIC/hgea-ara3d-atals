# HGEA · 3D ARA

3D hippocampal domains of the HGEA (Bienkowski et al., 2018) on the Allen Reference Atlas Nissl brain, also carried into CCFv3BBP.

**Web page:** https://center-for-integrative-connectomics-cic.github.io/hgea-ara3d-atals/

| Accuracy | |
|---|---|
| Plate placement in the 3D ARA | 8.3 µm |
| Fill between plates (leave-one-plate-out, 2× gap) | 0.643 |
| 3D ARA → CCFv3BBP (Nissl correlation, hippocampus) | 0.956 |
| Blue Brain ISH marker check (median AUC) | 0.809 |

**Build:** install `requirements.txt` and run `scripts/00`–`12` in order; the inputs are listed in `DATA_LICENSES.md`.
